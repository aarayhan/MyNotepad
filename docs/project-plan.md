# Project Plan

## Project Objective

Build MyNPad, a simple Laravel personal notes app where users can register, login, and manage their own notes.

## Timeline

- Week 1: Laravel setup, database setup, GitHub setup
- Week 2: Manual authentication routes, controller, and views
- Week 3: Notes migration, model relationships, and CRUD controller
- Week 4: Blade pages, Tailwind UI, and security checks
- Week 5: Testing, documentation, screenshots, and presentation practice

## Team Role Division

- Member 1: Authentication routes, controller, and validation
- Member 2: Notes migration, model relationships, and CRUD logic
- Member 3: Blade views and Tailwind interface
- Member 4: Documentation, testing checklist, and presentation notes

## Task Breakdown

- Create Laravel project structure
- Configure MySQL database
- Build register page and logic
- Build login and logout logic
- Create notes table with `user_id`
- Add `User hasMany Note` relationship
- Add `Note belongsTo User` relationship
- Build notes dashboard
- Build create, show, edit, and delete note pages
- Add ownership checks for notes
- Write README and team docs
- Test all main features
